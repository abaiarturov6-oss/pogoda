# Погода

Небольшой сайт с текущей погодой и прогнозом для выбранного города.

## Возможности

- Поиск города или села по названию
- Текущая погода, ощущаемая температура, ветер, влажность и осадки
- Почасовой прогноз и прогноз на 7 дней
- Время восхода и заката
- Переключение °C/°F
- Сохранение любимых мест в браузере
- Поиск погоды по текущему местоположению

## Запуск

Нужен Python 3. Запустите локальный сервер из папки проекта:

```powershell
python server.py
```

Затем откройте http://127.0.0.1:8000/.

Сервер использует только стандартную библиотеку Python. Прогноз загружается из Open-Meteo, поэтому нужен доступ к интернету.

## Публикация

GitHub Pages не запускает Python API. Чтобы сайт с прогнозом работал в интернете, разместите `server.py` на хостинге для Python и настройте адрес API во фронтенде. Репозиторий GitHub хранит исходный код, но сам по себе не запускает API.
