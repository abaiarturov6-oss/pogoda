# Погода

Небольшой сайт с текущей погодой и прогнозом для выбранного города.

## Возможности

- Поиск города или села по названию
- Текущая погода, ощущаемая температура, ветер, влажность и осадки
- Почасовой прогноз и прогноз на 7 дней
- Время восхода и заката
- Переключение °C/°F
- Сохранение любимых мест в браузере
- Поиск погоды по текущему местоположению
- При недоступном GPS по умолчанию показывается Бишкек; другой город можно выбрать через поиск
- Определение погоды рядом с пользователем при открытии, обновление каждые 15 минут и при возвращении на сайт (если прогноз старше 5 минут)
- Браузерные уведомления о выбранных погодных явлениях (дождь, снег, гроза) в ближайшие 6 часов
- Выбор типов погодных уведомлений в меню «Настройки»
- Включение и настройка погодных уведомлений в меню «Настройки»
- Автоматическое определение местоположения при открытии можно отключить в «Настройках»
- Скачивание отдельной HTML-страницы для телефона

## Запуск

Для локального просмотра нужен Python 3. Запустите статический сервер из папки проекта:

```powershell
python -m http.server 8000
```

Откройте http://127.0.0.1:8000/. Прогноз загружается прямо из Open-Meteo, поэтому нужен доступ к интернету.
`pogoda-mobile.html` — отдельная копия сайта со встроенными стилями и скриптом. Для прогноза нужен интернет.
Для погодных уведомлений нажмите «Включить» и разрешите уведомления браузеру. Они проверяются при загрузке прогноза и обновляются, пока страница открыта; работа после закрытия сайта требует push-сервера.

## Публикация

Сайт можно разместить на GitHub Pages. После публикации откройте ссылку на телефоне и установите приложение из кнопки «Установить». На iPhone в Safari нажмите **Поделиться → На экран Домой**. Для загрузки прогноза нужен интернет.
